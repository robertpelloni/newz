# newz

**Design/spec repository** for a multi-source news and sentiment aggregator — "Google News on steroids": correlate the same story across Google News, Yahoo News, MSN, and Fox; merge in link-aggregator signals (Reddit, Hacker News, Lobsters, Digg, …) matched to those topics; read the articles *and* the comment threads; summarize both with highlights, topics, and sentiment; then layer social-media reaction (X/Twitter, Threads, LinkedIn, Mastodon, Facebook, 4chan) on top, presented as a topic-clustered news front page.

## Current state of this repo

This repo contains **only the design document** — the full architecture and execution blueprint (previously the entire README, written as a build brief for Google Jules to implement autonomously). There is no code here yet.

## Status

Spec stage. Treat this as the blueprint for the aggregator, not a runnable system.
