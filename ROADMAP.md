# ROADMAP

Major, long-term structural milestones and structural plans.

## Phase 1: Foundation (Completed)
- Scaffolding of Backend, Frontend, and Worker architecture.
- Database schema setup (PostgreSQL + pgvector).
- Basic UI dashboard implementation wired to dummy endpoints.

## Phase 2: Ingestion & Aggregation
- Implement basic RSS scrapers for mainstream news.
- Implement link aggregator API fetchers (Reddit, Hacker News).
- Initial topic clustering and embedding logic.

## Phase 3: AI & Sentiment Integration
- Integrate LLM pipeline for summarization and key highlights.
- Implement sentiment analysis for comments and social posts.
- Refine clustering with HDBSCAN.

## Phase 4: Polish & Scale
- Full social media integration (Twitter, LinkedIn, etc.).
- Robust rate limiting and error handling for scrapers.
- High-density dashboard enhancements (live updates, filters).
